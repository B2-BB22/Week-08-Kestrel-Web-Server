# ใบงานการทดลองที่ 8.2 (Labsheet 8.2)
### การสตรีมสัญญาณแอนะล็อก ESP32 ออกพอร์ตสื่อสารอนุกรม (UART)

**รหัสนักศึกษา:** 67030281  
**ชื่อ-นามสกุล:** นายชนินทร์ คำวงศ์ษา 

---

## วัตถุประสงค์การทดลอง (Objectives)
1. สามารถต่อวงจรตัวต้านทานปรับค่าได้ (Potentiometer) เข้ากับขาอินพุตแอนะล็อก (ADC) ของ ESP32 ได้อย่างถูกต้องและปลอดภัย
2. เข้าใจข้อจำกัดของวงจรแปลงสัญญาณแอนะล็อกเป็นดิจิทัล (ADC1 vs ADC2) บนบอร์ด ESP32
3. สามารถเขียนโปรแกรมภาษา C บน ESP-IDF v6.x เพื่ออ่านค่าและกรองสัญญาณรบกวน (Signal Smoothing ด้วย EMA Filter) ได้
4. สามารถสตรีมข้อมูลเซนเซอร์ออกทางพอร์ตสื่อสารอนุกรม (Serial Port @ 115200 bps) เพื่อเตรียมป้อนให้แก่ Web Server ได้

---

## อุปกรณ์และการต่อวงจร (Hardware Schematic & Wiring)

### 1. แผนผังการต่อสาย
```text
        ESP32 Board                  Potentiometer (10k)
      +--------------+                 +-------------+
      |         3.3V |-----------------| ขา 1 (VCC)  |
      |          GND |-----------------| ขา 3 (GND)  |
      |      GPIO 34 |-----------------| ขา 2 (Wiper)| (ขากลางรับแรงดัน 0 - 3.3V)
      +--------------+                 +-------------+
```

### 2. ข้อควรระวังและเหตุผลทางวิศวกรรม
1. **ระดับแรงดันไฟฟ้า:** ต้องต่อขา VCC ของ Potentiometer เข้ากับขา 3.3V เท่านั้น ห้ามต่อกับไฟ 5V (VIN) โดยเด็ดขาด เนื่องจากขา GPIO ของ ESP32 ทนแรงดันอินพุตได้สูงสุดไม่เกิน 3.6V หากป้อนไฟ 5V อาจทำให้วงจร ADC ภายในเสียหายได้
2. **การเลือกใช้ขา GPIO 34 (ADC1):**
   - บนบอร์ด ESP32 แบ่งคอนโทรลเลอร์ ADC ออกเป็น 2 ชุด คือ ADC1 (GPIO 32-39) และ ADC2 (GPIO 0, 2, 4, 12-15, 25-27)
   - ชุด ADC2 จะแชร์การทำงานร่วมกับระบบ Wi-Fi Driver เมื่อมีการเปิดใช้งาน Wi-Fi ระบบจะยึดสิทธิ์การใช้ ADC2 ทำให้ไม่สามารถอ่านค่าแอนะล็อกได้
   - ดังนั้น การเลือกใช้ GPIO 34 ซึ่งอยู่ในกลุ่ม ADC1 (ADC_UNIT_1, ADC_CHANNEL_6) จึงเหมาะสมและปลอดภัยที่สุด สามารถทำงานร่วมกับ Wi-Fi และ Bluetooth ได้อย่างต่อเนื่อง

## ซอร์สโค้ดเฟิร์มแวร์ ESP-IDF v6.x (`main/ESP32_ADC_Stream.c`)

```c
#include <stdio.h>
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"
#include "esp_log.h"
#include "esp_adc/adc_oneshot.h"

#if CONFIG_IDF_TARGET_ESP32C6
#define POT_ADC_CHANNEL    ADC_CHANNEL_4   // GPIO 4 บน ESP32-C6
#else
#define POT_ADC_CHANNEL    ADC_CHANNEL_6   // GPIO 34 บน ESP32 WROOM
#endif

void app_main(void)
{
    printf("\n[SYSTEM] ESP-IDF v6.x Potentiometer Stream Starting...\n");

    // 1. สร้างและตั้งค่า ADC Unit 1
    adc_oneshot_unit_handle_t adc1_handle;
    adc_oneshot_unit_init_cfg_t init_config1 = {
        .unit_id = ADC_UNIT_1,
        .ulp_mode = ADC_ULP_MODE_DISABLE,
    };
    ESP_ERROR_CHECK(adc_oneshot_new_unit(&init_config1, &adc1_handle));

    // 2. กำหนดค่าความละเอียด 12-bit (0-4095) และอัตราขยายสัญญาณ (Attenuation 12dB สำหรับ 0-3.3V)
    adc_oneshot_chan_cfg_t config = {
        .bitwidth = ADC_BITWIDTH_12,
        .atten = ADC_ATTEN_DB_12,
    };
    ESP_ERROR_CHECK(adc_oneshot_config_channel(adc1_handle, POT_ADC_CHANNEL, &config));

    printf("[SYSTEM] ADC Initialized with EMA Filter. Streaming values @ 115200 bps...\n");

    int raw_val = 0;
    float filtered_val = 0.0f;
    const float alpha = 0.25f; // ค่าสัมประสิทธิ์การกรอง Exponential Moving Average

    while (1) {
        // อ่านค่าแอนะล็อกแบบ Oneshot
        ESP_ERROR_CHECK(adc_oneshot_read(adc1_handle, POT_ADC_CHANNEL, &raw_val));

        // การกรองแบบ Exponential Moving Average (EMA) เพื่อลดสัญญาณรบกวน (Noise Reduction)
        filtered_val = (alpha * raw_val) + ((1.0f - alpha) * filtered_val);

        // สตรีมค่าตัวเลขออกทาง UART (stdout) บรรทัดละ 1 ค่า เพื่อให้ฝั่ง C# อ่านง่าย
        printf("%d\n", (int)filtered_val);

        // สตรีมที่ความถี่ 20 Hz (ทุก 50ms)
        vTaskDelay(pdMS_TO_TICKS(50));
    }
}
```

## ผลการทดสอบการหมุน Potentiometer
- **ตอนหมุนไปทางซ้ายสุด:** แรงดันที่ขา Wiper จะตกลงมาใกล้ 0V ค่า ADC ที่สตรีมออกมาจะอยู่ที่ประมาณ `0 - 15` ครับ
- **ตอนบิดมาไว้ตรงกลางๆ:** แรงดันที่ขา Wiper จะได้ประมาณ 1.65V ค่า ADC อ่านได้แถวๆ `2048` ครับ
- **ตอนหมุนไปทางขวาสุด:** แรงดันที่ขา Wiper จะวิ่งขึ้นไปใกล้ 3.3V ค่า ADC แสดงผลอยู่ที่ประมาณ `4080 - 4095` ครับ
- **ผลการใส่ EMA Filter (alpha = 0.25):**  
  ก่อนใส่ฟิลเตอร์ ตัวเลข ADC มันจะกระโดดแกว่งไปมา +-10 ถึง 20 จากพวกสัญญาณรบกวน แต่พอใส่สูตร EMA เข้าไปแล้ว ตัวเลขที่สตรีมออกมานิ่งขึ้นเยอะมาก และเวลาหมุนก็ตอบสนองได้เนียนลื่นตาขึ้นครับ

## [Checkpoint 2.1 ทดสอบความเข้าใจ]

### 1. ใน ESP-IDF v6.x ฟังก์ชัน `adc_oneshot_read()` คืนค่าผลลัพธ์เป็นตัวเลขแบบใด และมีช่วงค่าต่ำสุด-สูงสุดเท่าใดเมื่อตั้งค่าเป็น `ADC_BITWIDTH_12`
**คำตอบ:**  
- **ชนิดของตัวเลข:** คืนค่าออกมาเป็นเลขจำนวนเต็มครับ (เป็น int ผ่านพอยน์เตอร์ `int *out_raw`)
- **ช่วงค่าต่ำสุด - สูงสุด:** จะมีค่าอยู่ในช่วง **0 ถึง 4095** ครับ  
  เพราะว่าเราเซ็ตความละเอียดไว้ที่ 12 บิต ซึ่งจะได้ระดับสัญญาณทั้งหมด 2^12 = 4096 ขั้น (นับตั้งแต่ 0 ถึง 4095) โดยเลข 0 คือแทนแรงดัน 0V ส่วน 4095 ก็คือแทนแรงดันสูงสุดเต็มสเกลประมาณ 3.3V ตอนที่เราตั้ง Attenuation ไว้ที่ 12dB ครับ

---

### 2. ทำไมเราจึงต้องกดปุ่ม `Ctrl + ]` เพื่อปิด ESP-IDF Monitor ก่อนที่เราจะรันโปรแกรมฝั่ง C# Kestrel ในใบงานถัดไป
*(คำใบ้: หากโปรเซส idf.py monitor ยังเปิดค้างอยู่ จะเกิดอะไรขึ้นกับพอร์ต COM)*  
**คำตอบ:**  
เพราะว่าพวก Serial COM Port บนคอมพิวเตอร์มันยอมให้โปรแกรมเปิดใช้งานได้ทีละ 1 โปรเซสเท่านั้นครับ (Exclusive Access) ถ้าเรายังเปิด `idf.py monitor` ค้างไว้อยู่ ตัวมอนิเตอร์มันก็จะยึดพอร์ตนั้นไว้ พอเราไปสั่งรันโปรแกรม C# Kestrel แล้วโค้ดมันจะเรียกคำสั่ง `serial.Open()` บนพอร์ตเดิม มันจะฟ้อง error ทันทีว่า `UnauthorizedAccessException: Access to the port is denied` ทำให้โปรแกรมฝั่ง C# ไปต่อกับบอร์ด ESP32 ไม่ได้แล้วต้องตกไปรันโหมดจำลองแทน ดังนั้นเราเลยต้องกด `Ctrl + ]` เพื่อปิดหน้าจอมอนิเตอร์และปล่อยพอร์ตคืนให้ระบบก่อนครับ

## ภารกิจท้าทาย (Micro-Challenge) การประยุกต์ใช้วงจร LDR (Light Dependent Resistor)

### 1. แผนภาพวงจรแบ่งแรงดัน (Voltage Divider)
```text
        +3.3V
          |
         [ ] LDR (ความต้านทานเปลี่ยนตามความเข้มแสง)
          |
          +------> ต่อเข้าขา GPIO 34 (ADC1_CH6)
          |
         [ ] R1 (ตัวต้านทาน 10 kΩ)
          |
         GND
```

### 2. สมการแรงดันขาออก
`Vout = Vcc * (R1 / (R_LDR + R1))` โดย `Vcc = 3.3V` และ `R1 = 10 kΩ`

### 3. ผลการทดลองจริงที่สังเกตได้
1. **ตอนแสงสว่างในห้องปกติ:** ความต้านทานของ LDR จะอยู่แถวๆ 8 - 15 kΩ แรงดันตกคร่อม R1 จะได้ประมาณ 1.3 - 1.8V อ่านค่า ADC ออกมาได้แถวๆ `1600 - 2200` ครับ
2. **ตอนเอาไฟฉายมือถือมาส่องตรงๆ:** พอเจอแสงจ้าๆ ค่าความต้านทานของ LDR จะฮวบลงเหลือแค่ไม่กี่ร้อยโอห์ม ทำให้แรงดันที่ตกคร่อม R1 พุ่งขึ้นไปเกือบถึง 3.3V ค่า ADC เลยพุ่งสูงขึ้นไปเป็น `3800 - 4085` ครับ
3. **ตอนเอามือมาปิดบังแสงให้มืด:** พอไม่มีแสงตกกระทบ ความต้านทาน LDR จะดีดขึ้นสูงมากเป็นหลักแสนโอห์ม ทำให้แทบไม่มีกระแสไหล แรงดันตกคร่อม R1 เลยลดลงมาเกือบ 0V ค่า ADC ก็ดิ่งลงมาเหลือแค่ประมาณ `150 - 350` ครับ
